# Currency Tracker 💱

A Python-based currency tracker that lets you check exchange rates, view historical data, analyze trends, compare currencies, and track rate targets.

## Features

- Live exchange rates
- Historical rates & charts
- Technical indicators
- Risk analysis
- Currency comparison
- News sentiment
- Watchlist & rate targets
- Currency converter

## Tech Stack

Python • Pandas • NumPy • Requests • VADER • Feedparser

## Run

```bash
git clone https://github.com/hybrid-69/Currency-Tracker.git
cd Currency-Tracker
pip install -r requirements.txt
python app.py
```
